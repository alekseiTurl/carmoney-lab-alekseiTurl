# Разница режимов Kilo Code (Ask и Code)

- **Ask** — агент только читает и объясняет: разобрал Makefile и docker-compose.yml и выдал готовый текст раздела для README, но сам файл не тронул.
- **Code** — агент работает с репозиторием: тот же раздел сам лёг в README правкой, проверился через `git diff`.
- Итог: Ask — «подсказать», Code — «сделать»; ответ один и тот же, разница в том, кто его записывает.
